# MATLAB Result Plotting

This folder contains the MATLAB plotting layer for AMR experiments. Python
evaluation exports raw metrics and features only; these scripts read those
files and save figures under `result_plotting_matlab/figures`. Evaluation runs,
exported features (`feature_data/`), projection caches (`figure_data/`) and
generated figures are local artifacts excluded from Git. Obtain trusted
checkpoints and generate the required inputs before running these scripts.

## 1. Export Evaluation Results

Run evaluation from the `src` directory before plotting. The workflow below
uses O'Shea ResNet as the primary example:

```bash
python -m amc.evaluate --config configs/baselines/resnet.json --checkpoint runs/oshea_resnet/best.pt --output-dir runs/eval_oshea_resnet
```

The evaluation directory contains:

```text
metrics.json
evaluation_provenance.json
snr_accuracy.csv
modulation_snr_accuracy.csv
channel_accuracy.csv
channel_snr_accuracy.csv
confusion_matrix.csv
predictions.mat
tsne_features_0dB.mat
```

The last file is omitted when evaluation uses `--skip-feature-export`.
The provenance file is generated by evaluation and records the checkpoint hash,
selection, split and evaluated sample count for subsequent verification.

For the three-panel SAFTFormer feature visualization, run from `src`:

```bash
python -m amc.export_visualization_features
```

This exports the final-classifier input features for balanced test subsets
at Overall, 0 dB and 10 dB into `feature_data/`. Each subset has 300 examples
per class. Overall also balances all 20 SNR levels. Source indices,
checkpoint hash and prediction-agreement checks are saved alongside the
features; the original evaluation outputs are preserved.

To inspect ICSA and the internal STF-GLU layers without retraining:

```bash
python -m amc.export_layer_visualizations
```

The default export contains 48 seeded test examples: BPSK/QAM64/LFM,
AWGN/DoublySelective, 0/10 dB, four examples per cell. Selection uses no
predictions or activation values. `--classes`, `--channels`, `--snr-levels`,
`--samples-per-cell`, `--seed` and `--device` control extraction. For example:

```bash
python -m amc.export_layer_visualizations --classes QAM16 QAM64 QAM256 --channels AWGN --snr-levels 0 10 --samples-per-cell 4
```

The independent Python tool observes the original FP32/eval forward with
temporary hooks and verifies predictions against the formal `best.pt` test
evaluation. `feature_data/saftformer_layer_visualizations.mat` contains IQ,
59-by-6 ICSA gates, patch features at the embedding and six block outputs,
native branch/condition RMS values, relative RMS maps, spectral context,
checkpoint details and original sample indices. Add `--include-hidden` to
also retain the raw A/B and temporal-condition tensors. The JSON audit records
the selection, shapes, weight ranges and hook-free logit agreement.

with `eval_mcldnn` in the relevant entry script and update `outputPath` to a
model-specific filename. `run_plot_snr_compare.m` compares nine baselines
with the current Ours checkpoint.

Its input files are `snr_accuracy.csv` in the following directories under
`src/runs`:

| Curve | Evaluation directory |
| --- | --- |
| O'Shea ResNet | `eval_oshea_resnet` |
| MCLDNN | `eval_mcldnn` |
| CCTL-Net | `eval_cctl_net` |
| SE-TFA | `eval_se_tfa` |
| AMCNet | `eval_amcnet` |
| MCFormer | `eval_mcformer` |

| TLDNN | `eval_tldnn` |
| DHN | `eval_dhn` |
| SAFTFormer (Ours) | `eval_saftformer_full` |

FEA-T is excluded from the comparison. Ours uses the 48-dimensional,
six-head, six-layer model with 48-point frames and
stride 8, a unified SHE+ICSA frontend, and six dense 192-dimensional STF-GLU
branches with temporal kernels 1/3/5/7 and shared spectral conditioning.
Its epoch-41 `best.pt` checkpoint achieves 69.808485% overall test accuracy.
The evaluations cover the same 15 classes, 11 channels, and 660,000 test
samples. The comparison reads all 20 raw SNR points from each CSV, converts
fractional accuracy to percentages, and applies no smoothing.

## Figure Definitions

- `run_plot_saftformer_modules.m` shows the first seeded BPSK/AWGN/0 dB
  example, chosen before examining predictions or responses. Original I/Q traces
  and ICSA gates occupy the left column, with temporal and spectral condition
  maps on the right. Change `options.SampleIndex` to view another exported
  example. Gates are multiplicative weights, not softmax probabilities.
  Relative response RMS divides condition RMS by the pre-condition A/B branch
  RMS. Both response maps share a scale computed over all exported examples,
  and no map is normalized independently. These are activation magnitudes,
  not causal attribution scores. All six blocks, including the zero local
  responses of Block 6, are shown. In the CLS-only architecture, the last
  block's patch FFN has no subsequent path to the classifier. Native RGB
  cells/colorbars preserve vector PDF output and exact values in the FIG.

- `run_plot_saftformer_modulation.m` draws 15 SNR--accuracy curves from the
  formal SAFTFormer `best.pt` evaluation. Every curve retains its 20 measured
  points from -20 to 18 dB, averaged over all 11 channel conditions, with no
  smoothing. The vertical axis is accuracy in percent. Colors and filled
  markers follow the existing per-modulation SNR example, with a compact
  five-column, three-row legend inside the lower-right corner. The canvas is
  960 by 800 pixels, matching the comparison plot's frame, font, inward ticks
  and dotted grid. Axis limits are -20.5 to 18.5 dB and -2 to 102%, leaving
  space around all measured endpoints and plateaus. PDF, PNG and editable
  FIG outputs retain all 300 input accuracies, class names, source paths and
  provenance. The axis padding does not introduce extra measurements.

- `run_plot_saftformer_channel.m` draws all 11 channel-conditioned SNR curves
  from the same formal checkpoint, retaining all 220 measured values. Each
  channel/SNR cell averages the 15 modulation classes. Its canvas, axes,
  limits and PDF scale match the modulation chart on the Slides' Modulation
  and Channel Analysis page. Full channel names appear in the lower-right
  legend, including Frequency-selective Rayleigh and Rician. Every measured
  SNR point has a filled marker; no smoothing is applied.

- `run_plot_saftformer_modulation_radar.m` summarizes the same evaluation as
  one 15-spoke SAFTFormer curve. Each value is the class's mean accuracy
  across all 20 equally sampled SNR levels and all 11 channels. All spokes
  share an absolute 0--100% scale; values are not rescaled separately by
  class. This optional summary has a 1000-by-800-pixel canvas and is no longer
  included in the Slides. The FIG preserves all 300 source values, the class
  means and evaluation provenance.

- `run_plot_saftformer_confusion.m` places Overall, 0 dB and 10 dB count
  matrices in one row. Overall uses all 660,000 formal test examples; each
  selected SNR uses 33,000. Rows are true classes and columns are predictions.
  All 675 raw integer cells, including zeros, are annotated. Each panel has
  its own count color scale because the sample supports differ. Native RGB
  cells and colorbar strips retain vector PDF output. The FIG retains all
  counts, source prediction indices, class names and evaluation provenance.

- `run_plot_saftformer_tsne.m` shows Overall, 0 dB and 10 dB in three equal
  square panels, with a shared 15-class legend. Every panel uses 4,500 true
  48-dimensional classifier-input features from the same `best.pt` checkpoint,
  with 300 examples per class and balanced channel coverage. Overall also
  balances all 20 SNR levels. Each projection independently uses seed 42,
  perplexity 30, PCA and feature standardization, matching the existing t-SNE
  pipeline. Coordinates and absolute distances are not compared between
  panels. Source hashes and parameters validate the saved embedding cache in
  `figure_data/saftformer_tsne_embeddings.mat`; layout edits reuse the cache.

- `run_plot_dataset_overview.m` shows all 15 modulation classes as a 3-by-5
  grid at AWGN/18 dB. It uses the first stored test record in each class's
  corresponding cell and displays samples 1--128 of the original 512, with
  blue I and teal Q traces on a shared amplitude scale. It exports vector
  PDF, PNG and editable FIG; original signals and sample IDs are retained
  for traceability. This is a qualitative overview of independent bursts.
  Every panel uses a closed four-sided coordinate frame and inward ticks.

- `run_plot_dataset_examples.m` reads the first stored test record for QPSK
  at 10 dB in AWGN, DoublySelective and 3GPP_TDL_C. It exports a 1200-by-480
  figure with three I/Q panels and shared amplitude limits. These are
  independent bursts, not paired channel transforms of one waveform.
  The editable FIG retains raw signals, sample IDs and source metadata.

Both comparison figures use pure black text, matching the Slides body text:
MATLAB `[0, 0, 0]` (`#000000`). This covers coordinate labels,
ticks, channel labels/ranges, and legend text; algorithm colors are preserved.
Coordinate frames, SNR dotted grids, zoom boxes and connector lines also use
pure black. Radar spokes use `spokeOpacity = 1.0` and `spokeLineStyle = '--'`
for black dashed guides; the radar outer circle stays solid black. SNR grid
opacity is 1. Lower `spokeOpacity` values blend the guides against white
while retaining vector output.

- `plot_snr_accuracy_paper.m` draws overall accuracy versus SNR, with an inset
  for the high-SNR region. The configured axis uses -20 dB to 18 dB in 2 dB
  steps.
- `run_plot_snr_compare.m` draws ten comparison curves with English
  labels and an `Accuracy (%)` axis. Ours is highlighted in red. The full
  plot spans -20 dB to 18 dB; the inset spans 0 dB to 18 dB and 79% to 95%
  accuracy. The main plot is wider than tall, with a five-row/two-column legend at the
  upper left, filled markers at every measured SNR point in both axes, and
  inward ticks. The inset labels every 2 dB horizontally and every 2 percentage
  points vertically. A dashed high-SNR box connects to the inset below. It exports
  a PNG, a vector PDF, and an editable MATLAB FIG.
  Main ticks, axis labels, legend and inset ticks use 11, 12, 10 and 9 pt,
  respectively. Both comparison MATLAB windows are 960 by 800 pixels.
  Slides embeds both vector PDFs at the same 30% scale; content cropping
  does not cause the figures to use different text scales.
  Its brighter ten-color palette is adapted from [Paul Tol's scientific color
  schemes](https://sronpersonalpages.nl/~pault/), with coral red for Ours.
  This custom combination uses distinct line styles and marker shapes as well
  as color; it is not a canonical ten-color colorblind-safe scheme.
- Both comparison runners use 14-point main labels and legends, with 12-point
  detail labels (SNR inset ticks and radar bounds). Embed the two PDFs at the
  same scale to preserve matching text sizes in the presentation.
- `plot_modulation_snr_accuracy.m` draws one filled-marker curve for every
  modulation class over the same SNR range.
- `plot_channel_accuracy_radar.m` draws an 11-spoke radar with one closed
  curve per algorithm and independent accuracy bounds for each channel,
  following the reference tracking-paper layout.
  `run_plot_channel_compare.m` reads the same nine baselines and current
  Full `best.pt` evaluation as the SNR comparison, with unchanged model names,
  colors, equal line widths and filled markers. It preserves dataset channel
  order, uses no area fills and places a compact two-row/five-column boxed
  legend close below the radar. No chart title, subtitle or footnote is drawn.
  The comparison runner enlarges the circle within the same 960-by-800 canvas,
  with compact range-label spacing above the legend and unchanged font sizes.
  Channel names use 11 pt, range labels 9.5 pt, and the legend 10 pt.
  The radar MATLAB canvas is 960 by 800 pixels. Both plots use Times New
  Roman and export vector PDFs with the original compact margins.
  Values average all 20 SNR levels from -20 to 18 dB (step 2 dB) on the same
  660,000-sample test split. FS-Rayleigh/FS-Rician abbreviate
  FrequencySelectiveRayleigh/Rician. Each channel label shows its own
  `(lower accuracy, upper accuracy)` bounds in percent. For each channel,
  `lower = floor((2 * min - max) * 10) / 10` and
  `upper = ceil(max * 10) / 10`, with bounds limited to [0,100]. Thus the best
  algorithm lies close to the outer circle, and the lowest lies near half
  radius. The same rule uses all ten algorithms on every channel; raw
  accuracies are unchanged. Radius is `(accuracy - lower)/(upper - lower)`;
  radii and polygon areas are not a common absolute-accuracy scale across
  channels. Optional `axisLimits` overrides the bounds; out-of-range data
  cause an error rather than being silently clipped.
  It exports PNG, vector PDF and editable FIG files. The returned
  `comparisonTable` and FIG `UserData` preserve all 110 unrounded accuracy
  values, model/channel names, per-axis bounds and normalized radii for
  inspection.
- `plot_confusion_matrix_results.m` defaults to raw sample counts with every
  cell annotated, including zeros. `Normalization='row'` displays percentages;
  `AnnotationThreshold` changes annotations only, and `ExportFormats` enables
  PDF and editable FIG outputs. `VectorCells=true` draws count cells and their
  colorbar as native vector rectangles. It returns the figure and matrix data.
- `plot_tsne_features.m` reduces exported penultimate-layer features with
  PCA followed by t-SNE. All samples use circular markers, and color identifies
  the modulation class.
- `amr_class_colors.m` provides a shared muted color palette for modulation
  classes.

Evaluation samples t-SNE features evenly across modulation classes and channel
conditions. By default it exports 300 samples per class at 0 dB. To use another
SNR, re-run evaluation, for example:

```bash
python -m amc.evaluate --config configs/baselines/resnet.json --checkpoint runs/oshea_resnet/best.pt --output-dir runs/eval_oshea_resnet --feature-snr 12
```

Then update `featureFile` and `outputPath` in `run_plot_tsne.m`.

MATLAB Statistics and Machine Learning Toolbox is required for `tsne`.
