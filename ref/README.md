# Baseline references

References for the nine comparison algorithms used in this project. The names
match the result table and the model configuration index. Publisher PDFs are
not redistributed; use the linked publication pages and available author code.

1. **O'Shea ResNet.** T. J. O'Shea, T. Roy, and T. C. Clancy,
   "Over-the-Air Deep Learning Based Radio Signal Classification,"
   *IEEE Journal of Selected Topics in Signal Processing*, vol. 12, no. 1,
   pp. 168-179, 2018.
   [DOI](https://doi.org/10.1109/JSTSP.2018.2797022) |
   [arXiv](https://arxiv.org/abs/1712.04578)

2. **MCLDNN.** J. Xu, C. Luo, G. Parr, and Y. Luo,
   "A Spatiotemporal Multi-Channel Learning Framework for Automatic Modulation
   Recognition," *IEEE Wireless Communications Letters*, vol. 9, no. 10,
   pp. 1629-1632, 2020.
   [DOI](https://doi.org/10.1109/LWC.2020.2999453) |
   [Author code](https://github.com/wzjialang/MCLDNN)

3. **CCTL-Net.** W. Wang, X. Zou, Z. Pan, and H. Zhao,
   "A Complex-valued hybrid deep learning models for automatic modulation
   recognition," *EURASIP Journal on Advances in Signal Processing*,
   vol. 2025, article 46, 2025.
   [Publication](https://link.springer.com/article/10.1186/s13634-025-01254-3)

4. **AMC-Net.** J. Zhang, T. Wang, Z. Feng, and S. Yang,
   "AMC-Net: An Effective Network for Automatic Modulation Classification,"
   *IEEE International Conference on Acoustics, Speech and Signal Processing
   (ICASSP)*, 2023.
   [arXiv](https://arxiv.org/abs/2304.00445) |
   [Author code](https://github.com/zjwfufu/AMC-Net)

5. **MCformer.** S. Hamidi-Rad and S. Jain,
   "MCformer: A Transformer Based Deep Neural Network for Automatic Modulation
   Classification," *IEEE Global Communications Conference (GLOBECOM)*,
   pp. 1-6, 2021.
   [DOI](https://doi.org/10.1109/GLOBECOM46510.2021.9685815)

6. **MCCFN.** A. Li, Y. Li, Q. Zhang, and P. Chen,
   "A Multi-scale Complex-valued Convolutional Fusion Network for Automatic
   Modulation Recognition," *Mobile Networks and Applications*, 2026.
   [DOI](https://doi.org/10.1007/s11036-026-02513-9) |
   [Author code and citation](https://github.com/Miraitwo/MCCFN)

7. **TLDNN.** Y. Qu et al.,
   "Enhancing Automatic Modulation Recognition through Robust Global Feature
   Extraction," arXiv:2401.01056, 2024.
   [arXiv](https://arxiv.org/abs/2401.01056)

8. **DHN.** J. Nie et al.,
   "Deep Hierarchical Network for Automatic Modulation Classification,"
   *IEEE Access*, vol. 7, pp. 94604-94613, 2019.
   [DOI](https://doi.org/10.1109/ACCESS.2019.2928463)

9. **SE-TFA.** S. Lin, Y. Zeng, and Y. Gong,
   "Modulation Recognition Using Signal Enhancement and Multistage Attention
   Mechanism," *IEEE Transactions on Wireless Communications*, vol. 21,
   no. 11, pp. 9921-9935, 2022.
   [DOI](https://doi.org/10.1109/TWC.2022.3181026)
