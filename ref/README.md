# Literature References

This folder records the main papers consulted for dataset design, baseline
reproduction, and AMR model research. Local PDF copies are excluded from the
public repository; use the publisher or arXiv links below.

   [DOI](https://doi.org/10.1109/JSTSP.2018.2797022) |
   [arXiv](https://arxiv.org/abs/1712.04578)
2. J. Xu, C. Luo, G. Parr, and Y. Luo, "A Spatiotemporal Multi-Channel Learning
   Framework for Automatic Modulation Recognition," *IEEE Wireless
   Communications Letters*, vol. 9, no. 10, pp. 1629-1632, 2020.
   [DOI](https://doi.org/10.1109/LWC.2020.2999453) |
   [Official code](https://github.com/wzjialang/MCLDNN)
